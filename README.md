# -RNA-Sequence-Data-Analysis-uing-R
RNA-Seq data analysis was performed using R, focusing on a real-world dataset published by Blanco-Melo et al. in Cell in 2020. In this project, primary cells, normal human bronchial epithelial cells (NHBE), were infected with respiratory viruses, and the resulting data were compared to understand the distinct host responses triggered by the virus.
